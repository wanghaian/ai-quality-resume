# 王海安交互式简历

直接打开 `index.html` 即可预览。

## 媒体文件

- `assets/avatar-front-v1.png`：当前静态人物基准图。
- `assets/head-turn.mp4`：首屏4秒左右转头视频。当前为静态占位视频，可直接用正式素材覆盖。
- `assets/close-up.mp4`：第二页多角度特写视频。当前为静态占位视频，可直接用正式素材覆盖。

视频应保持16:9，并尽量使用固定人物身份、服装、背景和光照。网页会通过 `seeked` 事件串联时间轴跳转，避免高频鼠标与滚动输入造成seek丢失。

## 交互

- 首屏：鼠标横向相对位置映射到视频时间轴，灵敏度系数为0.8。
- 第二页：页面滚动进度映射到特写视频时间轴。
- 移动端：三个方向按钮替代持续鼠标输入。
